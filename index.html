Personal Interests

My primary interest is computer science in the broad sense: I am fascinated both by theoretical foundations and by the practical engineering of software systems. Over time this has translated into focused work in several areas.

Programming Languages

I have a long-standing interest in programming languages, their design, and their trade-offs. My main practical language is C, which I appreciate for its closeness to the machine, its predictability, and its efficiency. According to a well-known study on energy efficiency across languages (ACM SIGPLAN, 2017), C is the fastest and most energy-efficient choice across a broad range of programming problems — a result that aligns well with the argument made by Bjarne Stroustrup that software efficiency is, in a broad sense, also an ecological choice. Beyond C, I follow developments in several other languages and enjoy understanding how different paradigms approach the same problems.

Software Architectures

I am actively working on and interested in cloud-native and distributed systems design, including microservices architectures, service mesh patterns, asynchronous messaging (Kafka, NATS, RabbitMQ), API design, and orchestration. I pay particular attention to interoperability, federation, and the challenges of building systems that span multiple administrative domains.

Cloud Orchestration and OASIS TOSCA

I have been working on TOSCA (Topology and Orchestration Specification for Cloud Applications), the OASIS standard language for describing cloud workloads and their lifecycle management. I currently follow and contribute to the activity of the OASIS TOSCA community, with specific interest in cloud federation scenarios and Kubernetes profiles.

Algorithms and Data Structures

I enjoy studying and implementing algorithms and data structures, especially those oriented toward efficiency in time and memory. I have written a C library (libfmrt) based on AVL trees for fast in-memory table management, and I regularly follow resources such as the NIST Dictionary of Algorithms and Data Structures.

Software

Below is a list of software tools and libraries I have written over time, all licensed under the Apache License v2.0. Source code is available on GitHub; there is no binary download provided here.

csv2mdText

A Linux command-line tool that generates a Markdown document by extracting data from a CSV table and applying a user-defined template. Useful for automating repetitive document production (e.g. product catalogs, specification tables). The resulting Markdown can be converted to other formats such as DOCX or PDF using tools like pandoc.

🛠 View on GitHub

importToscaDescWinery

A Linux command-line tool that parses a TOSCA YAML descriptor (type definitions or topology template) and reorganizes its content into a folder structure suitable for import into Eclipse Winery, the open-source TOSCA graphical modeler. Realized for my company and released as open source.
Background: TOSCA is an OASIS standard for describing cloud workloads, their components, relationships, and lifecycle management processes.

🛠 View on GitHub

libfmrt — Fast Memory Resident Tables Library

A C library (statically or dynamically linkable to C/C++ programs) for fast management of large in-memory tables. Data is organized as AVL trees, providing O(log2N) complexity on search, insert, and delete operations. Not a database: no persistence, no SQL, no joins. Suitable for in-memory caches and high-performance temporary data management.

🛠 View on GitHub

libmixf — Mixed Functions Library

A general-purpose C utility library collecting routines written over time for different projects. Organized into the following functional categories:

  • File and File System Handling
  • Time and Date Handling
  • String Handling
  • Configuration Files Handling
  • Log Handling
  • License Handling
  • Lock Handling
  • Counters Handling

First released in October 2019 as libmisc. Renamed to libmixf in June 2021 when licensed under Apache v2.0 (current version: v2.1.0).

🛠 View on GitHub

libclirunner — Minimal C solution for running external programs

libclirunner is a compact and robust C library that provides minimal, safe, dependency-free C Library for managing external processes.
